# Simulation Execution SDD Specification

对应 `SRS-FR-SIM-001` 至 `SRS-FR-SIM-008`。

## Acceptance slices

1. 顶部显示模拟时钟、行情时间、当前批次、数据质量、待风控数量和部分成交数量。
2. 信号流展示策略、标的、信号原因、目标仓位、生成时间和数据快照链接。
3. 委托表展示标的、策略、方向、委托数量、剩余数量、价格、状态和时间。
4. 筛选支持策略、标的、状态和买卖方向组合；空结果提示下一步。
5. 行情延迟/缺口时保持暂停，说明新开仓被阻断；恢复前需要重新通过数据门禁，平仓/撤单仍可执行。
6. 时间线固定串联信号、风控、委托、成交、记账五类事件。
