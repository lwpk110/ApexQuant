# ApexQuant SDD 模板

本文是页面/模块进入开发前的强制规格模板。只有本文件各节完成、需求追踪完整、原型输入已确认或记录偏差，并通过评审门禁后，才能开始 TDD 实现。

## 1. 文档元数据

| 字段 | 内容 |
| --- | --- |
| SDD ID | `SDD-<MODULE>-0.0.1` |
| 对应 SRS | `SRS-FR-*`、`SRS-BR-*` |
| 原型入口 | Open Design/Figma 页面、节点 ID、截图版本 |
| 状态 | Draft / Reviewed / Implementing / Verified / Superseded |
| 评审人 | 产品、设计、工程、测试 |
| 变更记录 | 日期、变更、原因、影响 |

## 4. 领域对象与数据契约

为每个实体定义 ID、必填字段、类型、单位、精度、时区、版本和来源。结果必须能反查 `strategy_version → data_version → cost_model → run_id`。

## 5. 状态与事件

定义状态枚举、合法转换、阻断条件、事件名称、事件载荷和审计要求。禁止用 UI 文案代替状态模型。

## 6. 页面结构与交互

定义区域、字段、组件、默认值、键盘行为、焦点返回、加载/空/错误/延迟/长任务/危险确认状态。

## 7. API 与端口

定义请求、响应、错误码、幂等键、运行 ID、权限边界和适配器来源。页面不得直接依赖 fixture 作为最终契约。

## 8. 非功能与视觉约束

引用 `DESIGN.md` token、1440px/1180px/移动端断点、可访问性、性能和安全要求。

## 9. TDD 计划

先写失败测试，至少覆盖：正常、空、错误/延迟、危险操作、关键状态转换和 API 错误。记录红灯命令、失败原因、绿灯命令和结果。
