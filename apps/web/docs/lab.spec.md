# Strategy Lab SDD Specification

对应 `SRS-FR-LAB-001` 至 `SRS-FR-LAB-008` 和 `AQ-LAB-*`。

## Acceptance slices

1. 三栏工作区同时展示策略列表、参数与数据配置、信号/净值/因子分析。
2. 策略列表展示生命周期、最近收益、最近实验 ID/时间；当前策略状态使用六态之一。
3. 配置面板包含股票池、运行周期、数据范围、复权方式、因子/特征、模型版本、单票仓位上限和交易成本模型。
4. 分钟级数据延迟或缺口时，数据质量门禁显示具体数值并阻断验证/模拟入口。
5. 数据泄漏检查失败时显示错误原因和运行 ID；样本外评估通过后才显示“可模拟”。
6. 保存草稿、验证策略、复制策略和创建实验均产生明确反馈，不跳出当前上下文。
