# Backtest Center SDD Specification

对应 `SRS-FR-BT-001` 至 `SRS-FR-BT-007`。

## Acceptance slices

1. 单页配置同时包含策略版本、数据版本、周期、日期、初始资金、信用参数、费用、滑点、成交假设、基准和随机种子。
2. 运行摘要显示运行 ID、状态、阶段、进度、耗时、数据泄漏检查、样本外范围和成本模型。
3. 结果指标显示年化收益、波动率、夏普、最大回撤、胜率、换手、交易成本占比、融资利息、融券费用和强平次数。
4. 指标、净值、交易明细、成本四个视图可切换；交易明细保留可复制的运行 ID和版本信息。
5. 对比模式最多选择 4 个实验；数据版本不一致时显示警告，不混绘结果。
6. 运行按钮创建可追溯的运行快照，不发送真实委托。
